# Place Your SWF File Here

This directory should contain your Flash game file.

## Instructions:

1. Place your `.swf` file in this directory
2. Name it `game.swf` OR
3. Update the filename in `index.html` to match your SWF filename

Example:
```
app/src/main/assets/
├── index.html
├── game.swf          <- Your Flash game here
└── README.md         <- This file
```

## Where to get Flash games:

- Export from Flash/Animate
- Use existing SWF files you have
- Find free Flash games online (respect copyright)

## Supported formats:

- `.swf` (Flash movies and games)

Note: This template uses Ruffle, which may not support all Flash features.
Test your game thoroughly to ensure compatibility.
